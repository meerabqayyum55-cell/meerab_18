ATMOS — MIDNIGHT SKY BLUE WEATHER ATLAS

Files:
- index.html: complete website (HTML, CSS, JavaScript)
- Atmos_Midnight_Sky_Blue_Report.docx: updated assignment report

Theme:
- Deep Night #0F141E
- Glassy Slate #1C2333
- Border #2A3449
- Primary text #FFFFFF
- Secondary text #94A3B8
- Sunny accent #FBBF24
- Sky blue #0EA5E9
- Rain accent #38BDF8

Run:
1. Extract the ZIP.
2. Open terminal/command prompt in the extracted folder.
3. Run: python -m http.server 8000
4. Open http://localhost:8000
5. Internet is required.
